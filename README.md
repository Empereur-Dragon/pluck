pluck takes care of this for you. When the app starts, it checks whether its built-in tools are current. If a newer version is available, pluck fetches it quietly in the background. You do not need to download anything manually, and you do not need to replace any files yourself.

The practical result is simple: pluck keeps working even as the sites it talks to get updated.

## 🛠️ Troubleshooting

**The app will not open the first time.**
Your computer is asking for confirmation because the app was downloaded from the internet. Approve it once and the prompt will not appear again.

**A download fails immediately.**
Check that the link is complete. Some sites use shortened links that break when only part of the address is copied. Try copying the address again from the browser bar.

**A download is very slow.**
Speed depends on the source site and your internet connection. Try a lower quality option if you are in a hurry.

**Spotify playlists are not appearing.**
Make sure you are signed in to Spotify in the app and that your playlist is not set to private. Private playlists cannot be read by any external application.

**Something looks out of date.**
Close pluck and open it again. The app checks for updated tools each time it starts.
